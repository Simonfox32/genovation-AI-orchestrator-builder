# Generated backend

A FastAPI backend with a SQLite database (SQLAlchemy 2), generated by AI Build Router: a tester agent wrote the
requirements and tests, a builder agent wrote the code until every test passed.

## What's here

| Path | What |
|---|---|
| `tests/REQUIREMENTS.md` | What this backend does, as numbered requirements (plus the assumptions made) |
| `tests/test_app.py` | One test per requirement |
| `app/main.py` | The API endpoints |
| `app/models.py` | The database tables |
| `app/schemas.py` | The shapes of requests and responses (if present) |
| `app/db.py` | The database connection (`app.db`, a SQLite file) |
| `tests/conftest.py` | Gives every test a fresh, empty in-memory database |

## Run it

Needs Python 3.12 or newer.

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Check it works:

```bash
python -m pytest -q
```

Start the server:

```bash
uvicorn app.main:app --reload
```

Then open **http://localhost:8000/docs**: an interactive page listing every endpoint. Pick one, click
**Try it out**, fill in the request, and **Execute**.

Data is saved in `app.db` in this folder. Delete that file to start again with an empty database.

## Using another database

The database URL is in `app/db.py` (`DATABASE_URL`). Because the code uses SQLAlchemy, it can point at PostgreSQL
(for example Supabase) instead of SQLite; you'd also install a driver such as `psycopg[binary]`, and remove the
SQLite-only `check_same_thread` and foreign-keys settings.
